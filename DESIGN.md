# Apeiron movement map

Vibe: focused training app. The map is the primary object, so chrome stays quiet and the athlete art provides the character.

- Canvas: solid graphite field with world-anchored tier guides. No animated beams, radar panel, or decorative grid.
- Nodes: generated athlete artwork, one consistent tile shape, and state expressed through a single status indicator.
- Motion: direct drag, soft bounds, momentum handed into a critically damped settle. Hover changes colour only. Reduced motion disables camera settling.
- Type: system UI font, seven-role scale, sentence case labels.
- Colour: saffron for progress, branch colour for wayfinding, graphite and off-white for structure.
